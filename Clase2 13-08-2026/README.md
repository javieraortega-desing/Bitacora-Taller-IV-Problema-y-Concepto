# Registro de exploración

Antes de la clase comenzamos a experimentar con **cables, protoboard y componentes electrónicos**.

Fue mi primer acercamiento a una **protoboard**, por lo que tuve varias dificultades para entender las conexiones y el funcionamiento del circuito.

### Proceso

* Primeros intentos de conexión.
* Pruebas con cables y componentes.
* Varias fallas y conexiones incorrectas.
* Corrección y repetición de las pruebas.
* Comprensión progresiva del funcionamiento de la protoboard y el circuito.

El proceso fue principalmente de **prueba y error**. A pesar de las primeras fallas, logramos llegar a un **circuito funcional** que, al recibir una señal de ruido mediante un micrófono, activa una **luz LED y un motor vibrador tipo moneda**.

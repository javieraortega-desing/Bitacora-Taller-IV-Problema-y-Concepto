# CORRECCIONES DEL PROFESOR

Durante la clase, el profesor nos indicó nuevas modificaciones para mejorar el funcionamiento de nuestro prototipo:

- Crear un **mecanismo para sostener la cabeza**.
- Lograr que, cuando el artefacto comenzara a vibrar, **la cabeza se cayera**.
- Incorporar otro mecanismo que permitiera **volver a colocar la cabeza en su posición utilizando un hilo**.

Estas correcciones serán fundamentales para la siguiente clase, ya que corresponde a la **ENTREGA FINAL DE LA SOLEMNE**.

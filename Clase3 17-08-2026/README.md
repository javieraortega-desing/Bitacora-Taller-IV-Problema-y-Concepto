#  Apuntes de clase

### Fenómeno → Percepción → Representación → Interpretación

* **Fenómeno:** algo que ocurre en el mundo.
* **Percepción:** capacidad de un organismo para relacionarse con el mundo.
* **Representación:** formas de describir ese algo.
* **Interpretación:** le atribuimos significado.

Nuestras experiencias etiquetan el mundo y nuestros sentidos determinan lo que podemos conocer y denominar.

* Lo que experimentamos está restringido por lo que nuestro cuerpo puede hacer.
* **Semiótica:** significado, significante, signo, ícono, índice y símbolo.
* **Diseñar es poder:** implica manipular comportamientos.
* No diseñamos solo objetos que perciben la realidad. Diseñamos **sistemas que seleccionan fenómenos, los traducen en datos y actúan a partir de una interpretación operacional**.
